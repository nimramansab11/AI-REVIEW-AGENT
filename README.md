# ReviewAI — Intelligent Content Reviewer

ReviewAI is an AI-powered content review application built with **FastAPI, LangGraph, and Large Language Models (LLMs)**. It helps users analyze written content and receive feedback on grammar, clarity, quality, relevance, and structure.

## Features

- **AI-Powered Content Review:** Analyze paragraphs, essays, reports, and other written content.
- **Multi-Agent Workflow:** Organize content review into specialized review stages using LangGraph.
- **Grammar & Clarity Analysis:** Identify language issues and improve readability.
- **Structure & Organization:** Evaluate the flow and organization of written content.
- **Interactive Web Interface:** Submit content and view the generated review.
- **Loading & Error Handling:** Display analysis progress and relevant error messages.
- **Clear Input:** Easily clear the current content and start a new review.
